# ToDo List Android App

This is a simple **To-Do List Android application** built using **Kotlin** and **SQLite**. The app allows users to **add, view, update, and delete notes**. All notes are stored locally using SQLite, ensuring that data persists even after closing the app.

The app features a **RecyclerView** to display notes, and each note can be edited or deleted. It uses **View Binding** for easy access to UI elements and provides a clean and user-friendly interface for managing notes efficiently.
